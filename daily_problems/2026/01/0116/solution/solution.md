这道题是典型的`求子数组的个数`的题目。<br>
灵神的模板说的是：
一般要写 `ans += right - left + 1`。内层循环结束后，`[left,right]` 这个子数组是满足题目要求的。
由于子数组越短，越能满足题目要求，所以除了 `[left,right]`，还有 `[left+1,right], [left+2,right], ..., [right,right]`
都是满足要求的。
也就是说，当右端点固定在 `right` 时，左端点在 `left, left+1, ..., right` 的所有子数组都是满足要求的，这一共有
`right−left+1` 个。<br/>
---
但是我们这里需要注意的一点，对于我来说，是：

```python
if k <= 1:
    return 0
```

其实是这里，我们来分析一下：首先如果我们不写这段代码的时候，当我们的`k = 0` 或者`k = 1`的时候，由题目中的提示可以看出
提示：<br>
1 <= `nums.length` <= 3 * $10^4$ <br>
1 <= `nums[i]` <= 1000<br>
0 <= `k` <= $10^6$ <br>
我们的数组长度最少是`1`的， 且数组中的每一个元素都是正整数，所以，当我们的 `k = 1`的时候，因为我们要返回 小于`k`的子数组的个数，
数组长度为`1`，因为它的乘积` ≥ 1`，所以不满足` < k`；数组长度如果不为`1`, 那么根本不可能有 小于`k`的子数组的可能。<br>
当我们的`k = 0`的时候，那就更不可能了，我们数组中的每一个都是正整数，所以根本不可能子数组的乘积小于 `0`的情况。<br>

---
总结起来就是两种情况：

1. `k = 0`,任意子数组乘积` ≥ 1`,不可能 `<0`。
2. `k = 1`, 任意子数组乘积` ≥ 1`, 不可能 `< 1`。<br>
3.

核心：由于数组元素最小为 `1`，任意非空子数组的乘积最小为 `1`，
因此当 k <= 1 时，不存在乘积严格小于 k 的子数组。
