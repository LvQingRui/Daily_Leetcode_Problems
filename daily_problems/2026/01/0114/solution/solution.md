这道题其实刚开始思路错了，其实核心就是: 拿走的点数和 + 剩下的点数和 = 全部的点数和
这道题让我们求的是 一共拿走k张牌，每一次只能从first 或者 end 拿， 所以从这里我们就可以知道，没有拿走的牌一定是连续的，这是一个重点！
所以我们就可以求没有拿走的牌的最小值，用全部的点数和减去最小值，那就是我们的答案。

需要注意的是，如果我们要取走全部的牌，那一定返回的是全部的点数和，但是我为啥这里要单独说呢，这是因为在使用灵神模板的时候，我们需要在这一题考虑这一点：

```python
m = len(arr) - k  # 这是剩余的牌的数目,也是我们窗口的大小
...
...  # 一些代码
left = i - m + 1
```

在这里，如果`k = n`了，那我们的`m`就是 `0`，这就导致`left` 居然在我们`i`的右侧（窗口的左端点在右端点的右边），这就会坐标越界，从而报错，这里需要注意。
